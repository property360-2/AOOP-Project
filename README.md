# Gym Management System

A web-based system for managing gym memberships. Users can apply for membership, and admins can accept, decline, or manage applications.

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- PHP, MySQL
- XAMPP (for local server)
- [Optional] Some external JS/CSS libraries

## 📦 Installation

1. **Download or Clone** this repository:
   ```bash
   git clone https://github.com/yourusername/gym-management-system.git
Open XAMPP and start Apache and MySQL.

Import the Database:

Open phpMyAdmin (usually at localhost/phpmyadmin)

Create a new database (e.g., gym_system)

Import the provided .sql file from the project folder

Run the Project:

Place the project folder in htdocs (e.g., C:\xampp\htdocs\gym-management-system)

Open your browser and go to:

http://localhost/gym-management-system/
👥 Features
User registration and login

Apply for gym membership

Admin panel to manage memberships

Accept/decline applications
